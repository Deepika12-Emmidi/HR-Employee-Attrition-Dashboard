# HR-Employee-Attrition-Dashboard
Power BI dashboard for HR Employee Attrition Analysis with interactive KPIs and visualization.

## 📌 Project Overview
This project is an interactive HR Employee Attrition Dashboard developed using Power BI. It helps analyze employee attrition, identify trends, and support HR decision-making using interactive visualizations.

## 📊 Dashboard Features
- Total Employees KPI
- Employees Left KPI
- Attrition Rate KPI
- Employees Left by Department
- Employees Left by Age Group

## 🛠 Tools Used
- Power BI
- DAX
- Data Visualization
- HR Analytics

## 📈 Key Insights
- Total Employees: 1470
- Employees Left: 237
- Attrition Rate: 16.12%
- Research & Development has the highest employee attrition.
- Employees aged 26–35 have the highest attrition.
